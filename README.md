# Defend to Ascend

一款以修仙与山门阵法为题材的 2D 自由造路塔防游戏，结合迷宫规划、五行搭配与长期养成。

建设防线，守住山门，在持续积累中突破境界。

## 玩法方向

- **自由布阵**：利用有限的墙体与防御单位规划路线，组织火力，应对不同类型的敌人。
- **五行组合**：结合属性关系与效果顺序，让路线设计和单位搭配共同影响战局。
- **修炼成长**：探索制符、炼器、灵兽等流派，逐步拓展防御选择。
- **山门经营**：积累资源、建设山门、挑战 Boss，解锁新的成长与扩建空间。
- **放置积累**：防守自动进行，支持持续挂机与离线收益，重心在规划而非手速。
